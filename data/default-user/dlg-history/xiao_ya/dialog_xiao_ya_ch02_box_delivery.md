# 小芽第二章·交匣

=== start ===

> 药铺的门板虚掩着，屋里只点了一盏油灯。小芽把那只旧木匣放到柜台上，指头搭在匣沿上，没舍得松。

小芽: 老板……匣子在这儿。蜡封没动过。

陈景和: 嗯。放下吧。

蒙面人: 快点，现在就给我打开。

陈景和: 急什么。它在蛇洞里待了这么久，还能自己长腿跑了不成？

蒙面人: 少打岔。我们追这东西追了这么久，今天就要见个真章。

小芽: 老板……这里头装的到底是什么？

陈景和: 一件旧东西，你不需要知道。

> 蒙面人上前一步，手按在腰后的刀柄上。陈景和没看他，低头望着柜台上的木匣，目光落在蜡封上，停住了。

陈景和: 你要开，我就开。只是开完了，别后悔。

蒙面人: 少啰嗦！开！

> 陈景和伸出手，指甲挑开蜡封。一声轻响，匣盖弹起一道缝。一缕白烟从缝里爬出来，贴着柜台，缓缓往下淌。

陈景和: 退开。

> 白烟猛地炸开。小芽喉咙一紧，像灌进了又苦又辣的什么东西，眼前发黑，膝盖砸在地上，整个人栽倒下去。

@call consume_item xiao_ya_sealed_poison_box 1

> 小芽撑着地，支起半个身子。一个蒙面人倒在门口，一动不动。另一个趴在柜台脚边，脸朝下。屋里不见老板的身影。

> 没有应答。小芽动了动嘴，舌下那粒药不知什么时候碎了，碎渣泡在嘴里，又苦又凉。

> 风从门缝灌进来，油灯缩成一粒豆大的光。小芽把碎渣吐在手心，盯着看了好一会儿，手指慢慢收紧。

小芽: 你给我药的时候……是不是就知道，这匣子会杀人？
