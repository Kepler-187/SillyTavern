# 小芽第三章·收购药材

=== start ===

商队头领: 这就是你一直背着的药？药店烧成那样，你还把它们分得很细。

小芽: ……真的有人肯收我？
商队头领: 肯把东西理明白，也肯救人，这种人到哪儿都不该饿着。

商队头领: 我们明早去落霞镇。商行缺个识药、肯做事的人，你愿不愿意同行？
小芽: 我也能去吗？
商队头领: 你今天救了人，又卖的是正经货。通远商行不怕多一个肯干活的人。
小芽: 那……我想去。药篓和针我都会带上。

小芽: 药店没了，村里也没有人等着收这些药。
小芽: 可我不是只能留在这里。
商队头领: 车要出发了。
