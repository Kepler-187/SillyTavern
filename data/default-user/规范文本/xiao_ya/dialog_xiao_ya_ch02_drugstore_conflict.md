# 小芽第二章·店内冲突

=== start ===

> 两名蒙面人把小芽推进前堂，一左一右，把陈景和夹在中间。

蒙面人: 陈景和。十几年前那枚丹，是你路上捡的，还是从死人身上摸的？

陈景和: 我听不懂你在说什么。

蒙面人: 那我就直说——丹，交出来。我当你这些年没白躲。

陈景和: 小店只有草药。二位要买，明早再来。

蒙面人: 敬酒不吃。

@flash white 0.3

蒙面人: 一介药商，方才那下接得不生疏。你以前是医馆的人？

陈景和: ……我就是个开药铺的。

蒙面人: 开药铺的，手底下藏得住这种工夫？

陈景和: 常年搬药篓子……手上有点力气。

小芽: 放、放开我……！

蒙面人: 别动。

小芽: 老板……！

陈景和: 她跟这事没关系！放开她！

蒙面人: 你自身都难保了，还顾得上她？

陈景和: 唔……！
蒙面人: 我问你。丹，在哪？

> 陈景和趴在地上，喘了几口气，没有回答。
