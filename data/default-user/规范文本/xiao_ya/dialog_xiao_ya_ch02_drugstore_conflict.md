# 小芽第二章·店内冲突

=== start ===

> 两名蒙面人把小芽推进前堂，一左一右，把陈景和夹在中间。

蒙面人: 陈景和。十几年前那枚丹，是你路上捡的，还是从死人身上摸的？

陈景和: 我听不懂你在说什么。

蒙面人: 那我就直说——丹，交出来。我当你这些年没白躲。

陈景和: 小店只有草药。二位要买，明早再来。

蒙面人: 敬酒不吃。

> 蒙面人猛地出手。陈景和侧身格挡，接住第一下，没接住第二下——整个人被掀翻在地，撞倒了药柜。

@flash white 0.3

> 药材滚了一地。陈景和才撑起半截身子，又被一脚踩回地上。

蒙面人: 一介药商，方才那下接得不生疏。你以前是医馆的人？

陈景和: ……我就是个开药铺的。

蒙面人: 开药铺的，手底下藏得住这种工夫？

陈景和: 常年搬药篓子……手上有点力气。

> 另一名蒙面人绕到柜台边，拽住小芽的胳膊，按在台沿上。台面算盘被带落，哗啦摔到地上。

小芽: 放、放开我……！

蒙面人: 别动。

小芽: 老板……！

陈景和: 她跟这事没关系！放开她！

蒙面人: 你自身都难保了，还顾得上她？

> 陈景和挣着要起来，又被踩下去。额角磕在柜脚上，血顺着眉骨淌下来。

蒙面人: 我问你。丹，在哪？

> 陈景和趴在地上，喘了几口气，没有回答。
