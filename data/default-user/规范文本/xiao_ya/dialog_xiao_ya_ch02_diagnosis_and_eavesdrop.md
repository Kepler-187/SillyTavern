# 小芽第二章·后堂诊治

=== start ===

> 屋里光线发暗，帘子半掩着。

小芽: ……我这是，我睡了多久

陈景和: 一盏茶。手伸出来。

小芽: 嘶……好凉
小芽: 老板…诊钱……我的药钱还在柜台上，用那些……

陈景和: 诊钱不用付。你药篓里夹了一株赤背草，够抵了。

小芽: 赤背草叶背是红的，我药篓里没有红的。老板，您分明是不想收我的钱。

陈景和: 嘴倒利索。

小芽: 老板，我这伤……

陈景和: 蛇毒你不认得，又舍不得卖明早换粮的那篓草，就想着硬扛一夜？

小芽: ……以前的伤，睡一觉就轻了。

陈景和: 蛇毒不认这个理。

小芽: 那……那得怎么办？

陈景和: 别急。先歇着，我去前头抓两味药。
