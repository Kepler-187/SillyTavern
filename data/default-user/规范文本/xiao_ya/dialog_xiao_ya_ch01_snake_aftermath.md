# 小芽第一章·花蛇战后

=== start ===

> 山风从草叶间漏过来。蛇瘫在碎石上，尾巴抽了两下，慢慢不动了。

小芽: 总、总算……不动了。
小芽: 腿有点软……先缓缓。

> 小芽蹲下身，把散落的药草拢回篓边，袖口蹭过手腕，轻轻吸了口气。

小芽: 嘶。
小芽: 什么时候咬的……我怎么这会儿才觉着疼。
小芽: 别慌。先看看。

> 捋开袖口，手腕上一圈牙印，渗着血珠。只看了一眼，便把袖子放下。

小芽: 明天的口粮都在这篓里……不能动。
小芽: 可要是不管它，怕是走不回村。

> 咬住袖口一角，另一头绕着手腕连缠两道，牙和手一同使劲，勒到伤口四周泛白。

小芽: 嘶——！
小芽: 好、好了。
小芽: 药得留着，我能背回去……

> 背起药篓，把蛇从路中间拨到草丛里，朝村里走去。

小芽: 走吧。天黑前得到家。
