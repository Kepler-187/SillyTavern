# 小芽第二章·带匣返回

=== start ===

> 山道两边的树影越拉越长。小芽双手捧着那只旧木匣，一股药味从匣缝里钻出来，贴在鼻尖上，散不掉。

蒙面人: 脚踩实了，走快些
小芽: 快着呢……就是头有点晕，手上使不上劲
蒙面人: 摔了匣子，你这条命也一块儿摔了
小芽: 没摔。匣子还好好的，蜡封也没裂
蒙面人: 回到药铺去，把匣子亲手交到掌柜手里
小芽: 你们……到底要找什么？
蒙面人: 想活命，就别多问一句
小芽: 那到了药铺，我交了匣子，你们真会走吗？我一直很听话的呀——洞里那么黑我也进去了，蛇在脚边绕，我都没敢出声……
蒙面人: 看你听话不听话。别起跑路的歪心思
小芽: 我不跑，也跑不动……这匣子沉得像装了石头
蒙面人: 沉就对了，好东西，才沉
小芽: 可是掌柜的收下这东西，会出事吧？还有……你们一直问的仙丹，就是匣子里这个？
蒙面人: 那是他的事
蒙面人: 你再问一句，我就让你先尝尝
小芽: 我不问了……
蒙面人: 看见屋子了？快走
小芽: 到了……就快到了
蒙面人: 到了门口，把匣子递进去，别多看一眼
小芽: 我知道了

> 小芽在药铺门前站定，低头看着怀里的匣子，蜡封在暮色里泛着一点暗光。

小芽: 老板……是我。我回来了。
