# 小芽第二章·后堂诊治

=== start ===

> 屋里光线发暗，帘子半掩着。

小芽: 唔……我这是睡了多久呀
陈景和: 一盏茶。手伸出来，我瞧瞧
小芽: 嘶——好凉。老板，诊钱还没给呢，我的药钱还在柜台上，就用那些
陈景和: 诊钱不用付。你药篓里夹了株赤背草，拿它抵了，正好
小芽: 赤背草叶背是红的呀，我这篓里没有一片红的。老板，您就是不想收我的钱吧
陈景和: 嘴倒利索
小芽: 老板，那我这伤……
陈景和: 蛇毒你不认得，明早要拿去换粮的那篓草又舍不得动，就打算硬扛一夜？
小芽: ……以前的伤，睡一觉就轻了嘛
陈景和: 蛇毒不认这个理
小芽: 那我得怎么办呀
陈景和: 别急。你先歇着，我去前头抓两味药
