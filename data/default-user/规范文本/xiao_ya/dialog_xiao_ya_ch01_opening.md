# 小芽第一章·开篇

=== start ===

> 天刚亮，风从窗缝里钻进来，冻得人一缩。
小芽: 窗缝又灌风……比昨天还冷。
> 小芽裹着旧棉被坐起来。伸手碰了碰火塘，灰烬早凉透了。
小芽: 柴一根也没剩。
> 又去翻布包，翻到底也只摸到一点干粮。
小芽: 就剩这点了，捏一捏也就一口，一顿都撑不过去。
> 肚子饿得响了一声。把布包系回去，没再多看。
小芽: 柴的事，先欠着。
小芽: 趁露水没干，先去采三份车前草——蔫了，收药的不肯要。
小芽: 换了粮，再想柴。
> 背起药篓，篓底用草绳补过，还算牢靠。
> 推开门，山风裹着草叶水汽扑过来。
小芽: 真冷……早去早回。
> 门在身后合上。山脚的露水还重，草叶湿漉漉地亮着光。
