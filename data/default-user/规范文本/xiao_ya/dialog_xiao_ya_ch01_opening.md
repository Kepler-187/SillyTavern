# 小芽第一章·开篇

=== start ===

> 天刚亮，风还从破屋的窗缝里往里钻。
小芽: 窗缝漏进来的风，比昨天还冷。
> 小芽裹着旧棉被坐起来。火塘早就凉透了，灰烬摸上去都是冰的。
小芽: 柴……一根都没剩。
小芽: 布包里也只有小半块干粮。省着吃，也撑不到明天晌午。
> 肚子在这时候响了一声。
小芽: 柴先欠着吧。
小芽: 先上山采三份车前草。趁露水没干——露水一干，叶子发蔫，收药的就不爱要。
小芽: 换回粮来，再说柴的事。
> 背起药篓——篓底用草绳补过，还算牢靠。
> 推开漏风的木门，山风夹着草叶上的水汽扑到脸上。
小芽: 真冷。……早去早回吧。
> 门在身后关上。山脚的露水正重，草叶上湿漉漉地亮着。
